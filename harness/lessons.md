# Lessons

Reusable lessons that have been observed in real work on this repository.

Do not add one-off task notes here. Promote only patterns that are likely to
help future agents or maintainers.

## Current Lessons

- The repository is currently planning-first. Before implementation, use
  `PROJECT.md`, `docs/ARCHITECTURE.md`, `DESIGN.md`, and `docs/design/screens-v2/`
  as the source of truth.

## Lesson Candidate Rules

Promote a task finding here only when one of these is true:

- It appears in two or more tasks.
- It prevented or explained a real failure.
- It describes a risky boundary future agents are likely to miss.
- It maps directly to a repeatable validation command.
